# 🏥 Quality Medical Equipments

A modern, responsive, and professional healthcare website developed for **Quality Medical Equipments**, a medical equipment and healthcare solutions provider based in Islamabad, Pakistan.

The website presents the company's medical equipment, hospital solutions, biomedical services, healthcare consultancy, and technology services through a clean and user-friendly interface.

---

## 🌐 Project Overview

**Quality Medical Equipments** provides medical equipment and healthcare solutions for hospitals, clinics, laboratories, and other healthcare facilities.

This website was developed to provide a strong digital presence where visitors can explore the company's services, products, and healthcare solutions and easily get in touch with the team.

---

## ✨ Key Features

- Modern and professional healthcare UI
- Fully responsive design
- Mobile-friendly navigation
- Fixed responsive navbar
- Interactive hero slider
- Medical equipment and solutions showcase
- Services showcase
- Dedicated About page
- Dedicated Products page
- Dedicated Services page
- Contact and quotation section
- Click-to-call integration
- WhatsApp contact integration
- Smooth scroll animations
- Responsive footer
- SEO-friendly page structure
- Optimized Next.js architecture

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/DevHassanraza/quality-medical-equipments.git
```

Enter the project directory:

```bash
cd quality-medical-equipments
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

---

## 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```
